Motion Reel

Fünf Szenen, live im Browser gerechnet. Die Bewegung entsteht als Code auf deinem Gerät und läuft ohne Videodatei. Mit dem Lautsprecher-Button schaltest du den Ton dazu, der ebenfalls live erzeugt wird.

Typografie in Bewegung

Jeder Buchstabe steigt einzeln aus einer Maske auf, versetzt um wenige Hundertstel Sekunden. Dahinter wischen Farbflächen durchs Bild. Die Kurve heißt easeOutExpo: schneller Start, weiches Ausklingen.
